# Grão de Bruma — landing page

Landing page demonstrativa da **Grão de Bruma Cafés Especiais**, uma marca fictícia de cafés especiais da Mantiqueira de Minas.

> **Site demonstrativo.** Produtos, preços e estoque são ilustrativos. Nenhuma compra, pagamento ou envio é processado.

## O que tem na página

- Catálogo com 5 cafés: pesquisa, filtro por categoria, ordenação e escolha de moagem.
- Sacola funcional (salva no navegador) com subtotal; o checkout só mostra uma mensagem de demonstração.
- Escala de torra interativa, tabela de moagem por método, receitas de preparo e dúvidas frequentes.
- Vídeo de fundo no topo: espresso sendo extraído com o vapor subindo, em loop contínuo e sem som, com botão para pausar. No computador usa a versão horizontal e no celular a vertical.
- Animações: bruma que se dissipa no topo, paralaxe nas montanhas, seções que aparecem ao rolar, grão que voa até a sacola. Quem ativa "reduzir movimento" no aparelho vê a página sem animações.

## Como rodar

É um site estático, sem build: abra `index.html` no navegador ou publique a pasta no GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Arquivos

- `index.html`: estrutura e textos da página.
- `styles.css`: identidade visual (cores e fontes da marca) e animações.
- `data.js`: catálogo de produtos e fotos. Para trocar preço, descrição ou foto, edite só este arquivo.
- `app.js`: catálogo, sacola e interações.
